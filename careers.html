Career Options

Network Administrator

Network Administrators manage and maintain computer networks for organizations.

Cybersecurity Analyst

Cybersecurity Analysts protect systems and networks from cyber attacks.

Cloud Network Engineer

Cloud Engineers design and manage cloud-based network systems.

Skills Needed

  • Troubleshooting
  • Networking Knowledge
  • Security Awareness
  • Problem Solving
  • Communication Skills

Certifications

  • CompTIA Network+
  • Cisco CCNA
  • CompTIA A+

Personal Reflection

The career that interests me the most is Cybersecurity Analyst because I enjoy solving problems and learning how networks can be protected from attacks.
