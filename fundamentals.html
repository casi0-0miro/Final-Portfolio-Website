What is a Computer Network?

A computer network is a group of devices connected together to share information and resources. Networks allow computers, phones, and servers to communicate with each other.

Types of Networks

LAN: Local Area Network used in homes or schools.

WAN: Wide Area Network covering large distances like the internet.

WLAN: Wireless Local Area Network using Wi-Fi connections.

Network Devices

  • Router: Connects networks together.
  • Switch: Connects devices within a network.
  • Access Point: Provides wireless connectivity.
  • Client: A device requesting services.
  • Server: A device providing services.

Vocabulary

  • Bandwidth: Amount of data transferred over time.
  • Protocol: Rules for communication.
  • IP Address: Device identifier on a network.
  • MAC Address: Hardware identifier.
  • DNS: Converts website names into IP addresses.
