IP Addresses

An IP address identifies a device on a network. IPv4 uses numbers like 192.168.1.1, while IPv6 uses longer hexadecimal addresses.

Private IP Example: 192.168.0.5

Public IP Example: 8.8.8.8

MAC Addresses

A MAC address is a unique hardware address assigned to a device’s network card.

The first 3 octets identify the manufacturer. This is called the OUI (Organizationally Unique Identifier).
